Our mission

Learn by doing.

MSAS helps students develop practical skills in sports data and analytics through real datasets, technical workshops, and projects that matter.

01 / SKILLS

Technical workshops

Learn analytical tools and workflows in Python and R, from the fundamentals through applied sports analysis.

02 / PROJECTS

Real sports questions

Join project teams that work with real datasets, build original analyses, and communicate useful findings.

A network at Michigan
